Measurability of Characteristic Functions

A direct inverse-image proof for the characteristic function of a measurable set.

Dale Matthews

Proposition. Let \((X,\mathcal{M})\) be a measurable space. If \(E\in\mathcal{M}\), then the characteristic function \(\chi_E:X\to\mathbb{R}\) is measurable.

Proof

Define

\[ \chi_E(x)= \begin{cases} 1, & x\in E, \\ 0, & x\notin E. \end{cases} \]

To show that \(\chi_E\) is measurable, let \(V\) be an open subset of \(\mathbb{R}\) and consider

\[ \chi_E^{-1}(V) =\{x\in X:\chi_E(x)\in V\}. \]

If \(V\) contains both \(0\) and \(1\), then \(\chi_E(x)\in V\) for every \(x\in X\), so

\[ \chi_E^{-1}(V)=X, \]

which is measurable.

If \(V\) contains neither \(0\) nor \(1\), then

\[ \chi_E^{-1}(V)=\varnothing, \]

which is measurable.

If \(V\) contains \(1\) but not \(0\), then

\[ \chi_E^{-1}(V)=E, \]

which is measurable.

Finally, if \(V\) contains \(0\) but not \(1\), then

\[ \chi_E^{-1}(V)=E^c, \]

which is measurable. Therefore \(\chi_E^{-1}(V)\) is measurable for every open set \(V\subset\mathbb{R}\), and hence \(\chi_E\) is measurable. \(\square\)
