Characteristic Functions and Semicontinuity

Two level-set proofs connecting the topology of a set with the semicontinuity of its characteristic function.

Dale Matthews

Proposition. Let \(A\) be a subset of a topological space \(X\). If \(A\) is open, then its characteristic function \(\chi_A\) is lower semicontinuous. If \(A\) is closed, then \(\chi_A\) is upper semicontinuous.

Recall that \(\chi_A(x)=1\) when \(x\in A\), and \(\chi_A(x)=0\) otherwise. A function is lower semicontinuous when every set \(\{x:f(x)>\alpha\}\) is open, and upper semicontinuous when every set \(\{x:f(x)<\alpha\}\) is open.

Open sets

Suppose that \(A\) is open. We want to show that \(\{x:\chi_A(x)>\alpha\}\) is open.

If \(0\leq\alpha<1\), then

\[ \{x:\chi_A(x)>\alpha\} =\{x:\chi_A(x)=1\}=A, \]

which is open.

If \(\alpha\geq 1\), then

\[ \{x:\chi_A(x)>\alpha\}=\varnothing, \]

which is open.

If \(\alpha<0\), then

\[ \{x:\chi_A(x)>\alpha\}=X, \]

which is open. Therefore

\[ \{x:\chi_A(x)>\alpha\} = \begin{cases} X, & \alpha<0, \\ A, & 0\leq\alpha<1, \\ \varnothing, & \alpha\geq 1. \end{cases} \]

This set is open for every \(\alpha\in\mathbb{R}\), so \(\chi_A\) is lower semicontinuous.

Closed sets

Now suppose that \(A\) is closed. We want to show that \(\{x:\chi_A(x)<\alpha\}\) is open.

If \(0<\alpha\leq 1\), then

\[ \{x:\chi_A(x)<\alpha\}=A^c. \]

If \(\alpha>1\), then

\[ \{x:\chi_A(x)<\alpha\}=X. \]

If \(\alpha\leq 0\), then

\[ \{x:\chi_A(x)<\alpha\}=\varnothing. \]

Therefore

\[ \{x:\chi_A(x)<\alpha\} = \begin{cases} A^c, & 0<\alpha\leq 1, \\ X, & \alpha>1, \\ \varnothing, & \alpha\leq 0. \end{cases} \]

If \(A\) is closed, then \(A^c\) is open. Hence this set is open for every \(\alpha\in\mathbb{R}\), and \(\chi_A\) is upper semicontinuous. \(\square\)
